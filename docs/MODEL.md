# Модель и обработка документов

На странице «Настройки» отображаются состояние смысловой проверки и имя подключённой модели. Локальные проверки доступны и без внешней модели.

## Как выполняется проверка

Приложение извлекает из документа абзацы и строки таблиц. Локальные правила проверяют отдельные требования. При включённой смысловой проверке модель дополнительно сопоставляет требования по смыслу и возвращает замечания с цитатами и рекомендациями.

Перед каждым обращением к внешнему API пользователь подтверждает, что документ открытый и не содержит конфиденциальных данных. При выключенной смысловой проверке текст не отправляется провайдеру модели.

Ответ проверяется на формат, существование фрагментов и наличие цитат в исходном тексте. Если провайдер недоступен или ответ не прошёл проверку, сохраняется локальный результат с предупреждением. Все замечания модели требуют решения специалиста.

## Подключение

Для запуска с внешней моделью владелец рабочего пространства указывает настройки в локальном `.env`:

| Параметр       | Что указать                        |
| -------------- | ---------------------------------- |
| `LLM_ENABLED`  | `true` для включения модели        |
| `LLM_BASE_URL` | Базовый HTTPS-адрес API провайдера |
| `LLM_MODEL`    | Доступную модель с поддержкой JSON |
| `LLM_API_KEY`  | Полный ключ из кабинета провайдера |

Используется API, совместимый с Chat Completions. После сохранения настроек пересоздайте приложение:

```bash
docker compose up -d --force-recreate app
```

Успешный анализ отмечается режимом «Гибридный» в результате проверки. Состояние «Подключена» в настройках означает, что параметры заполнены; результат запроса также зависит от доступности провайдера и квоты аккаунта.

При выборе `openrouter/free` OpenRouter определяет доступную бесплатную модель для каждого запроса. Этот идентификатор обозначает маршрутизатор; фактическая модель может меняться. Для воспроизводимого сравнения результатов можно выбрать конкретную доступную модель.

## Источники и конфиденциальность

Ключ API хранится в окружении приложения и не передаётся в браузер. После разбора исходный бинарный файл не сохраняется, но извлечённый текст и результат проверки остаются в истории рабочего пространства до удаления проверки. Все пользователи с паролем видят общее пространство.

Приложение использует ограниченный каталог нормативных источников и не выполняет автоматический поиск актуальных редакций. Ссылки и рекомендации нужно проверять применительно к предмету и режиму закупки.
