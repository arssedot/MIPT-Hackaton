# API Контур ТЗ

Все операции работают на том же origin, что и интерфейс. Изменяющие запросы требуют `Origin`, точно совпадающий с `APP_ORIGIN`. Кроме входа и health, требуется cookie `procurement_session`. Ответ ошибки: JSON с полем `error`. Секреты не возвращаются API.

| Метод и путь               | Назначение                   | Успех                      |
| -------------------------- | ---------------------------- | -------------------------- |
| `GET /api/auth`            | Проверка текущей сессии      | `{authenticated: boolean}` |
| `POST /api/auth`           | JSON `{password: string}`    | 200 и HttpOnly cookie      |
| `DELETE /api/auth`         | Выход                        | 200                        |
| `GET /api/settings`        | Статус модели, её имя        | 200                        |
| `POST /api/reviews`        | Анализ multipart/form-data   | 201 и полный Review        |
| `GET /api/reviews`         | Последние 100 проверок       | Краткие записи             |
| `GET /api/reviews/{id}`    | Полный результат             | 200 либо 404               |
| `PATCH /api/reviews/{id}`  | Решение по замечанию         | Обновлённый Review         |
| `DELETE /api/reviews/{id}` | Удаление текста и результата | 200, идемпотентно          |
| `GET /api/health/live`     | HTTP-процесс работает        | 200                        |
| `GET /api/health/ready`    | БД доступна                  | 200 либо 503               |

## Проверка документа

Multipart содержит `file` (DOCX/TXT до 8 МБ), `useModel` (`true`/`false`) и `isPublic` (`true`/`false`). Без `isPublic=true` запрос с включённой моделью отклоняется. Требуется Content-Length; размер ограничивается до разбора формы. На reverse proxy следует дополнительно задать лимит тела 9 МБ.

Повреждённый, слишком короткий, слишком большой, защищённый или неподдерживаемый документ возвращает 400. Неверный пароль/отсутствие сессии — 401, неверный Origin — 403, превышение частоты — 429, внутренняя ошибка — 500. Сбой модели не означает сбой всей операции: сохраняется локальный результат с предупреждением.

Review содержит `id`, `name`, `createdAt`, `document`, `findings`, `engine`, `warnings`, `durationMs`, `decisions`. `document.blocks` содержит стабильные в пределах одной проверки id (`b1`, `b2`), текст, тип, раздел и адрес. `engine=local` означает, что смысловая проверка не завершилась; `hybrid` — что получен и проверен ответ модели. Это не оценка качества документа.

Замечание содержит категорию, severity (`high/medium/low`), confidence (`confirmed/review`), origin (`local/model`), цитату, основной `blockId`, связанные блоки, объяснение, рекомендацию и `sourceIds`. Confidence — класс доказательности, а не вероятностная метрика. SourceId ссылается только на каталог проекта; URL от модели не принимается.

PATCH принимает `findingId` (UUID существующего замечания) и `decision` (`accepted`/`dismissed`). Операция блокирует запись на время транзакции. Решение можно изменить повторным PATCH. API не содержит автоматической правки исходного документа.

Лимиты входа: 20 попыток входа и 12 запусков анализа в минуту на один серверный процесс. MVP рассчитан на локальную команду; для публичного доступа нужен внешний limiter и персональные учётные записи.
